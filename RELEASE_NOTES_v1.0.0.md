# v1.0.0

Первый стабильный релиз Скетчбука.

## Возможности

- Рисование от руки (перо/маркер/ластик), несколько блокнотов и страниц, вставка изображений.
- Хранение заметок на сервере (SQLite через Flask API) — доступ с любого устройства под своим логином, данные не теряются при очистке браузера.
- Логин и управление пользователями (создание, роль администратора, сброс пароля).
- Тёмная/светлая/чёрная темы, сворачиваемая боковая панель.
- Векторные иконки интерфейса вместо эмодзи, корректно окрашенные под тему.
- Сглаживание рукописных линий (сплайн Catmull-Rom) — окружности и кривые больше не выглядят гранёными.

## Технически

- Деплой на сервер через `deploy/deploy.sh` (первичная установка) и `deploy/update.sh`/`redeploy.sh` (обновления).
- Поддержка предпросмотра в GitHub Codespaces (`.devcontainer/`).
